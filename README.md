# summry-library

纸间 · 私人双语书摘。纯前端，内容保存在当前浏览器的 IndexedDB，不上传阅读记录。

## 使用

打开 `index.html`，或通过 GitHub HTML Preview / 静态站点访问。同一浏览器、同一网站地址来源下，刷新或关闭后重新打开会读取已有记录。示例数据仅在首次使用时创建，删除的记录不会在下次打开时重新出现。

- 中文 / 英文书库，书籍新增、修改、删除和分类筛选。
- 每本书独立管理摘录，支持新增、编辑、删除及文字感想。
- 灵感信箱中的「总览」展示未归类和已归类记录，归入书籍后也可在书籍感想查看。
- 书名、作者、摘录、生词搜索。
- JSON 备份导出和恢复。恢复前校验格式、记录 ID 与书籍关联；恢复会替换当前数据。

浏览器清理网站数据、无痕窗口结束或更换浏览器/设备会影响本地数据；请定期导出备份。保存失败会明确提示，且不会假报删除成功。浏览器不允许存储时，可下载 `index.html` 用普通浏览器打开或允许网站存储。

拍照划线 OCR 和语音转写仍未实现，当前不会假报 OCR 或录音保存成功。可使用手动录入和文字感想。

## 源码与构建

- `app-shell.html`：页面结构、样式与首次示例记录。
- `app.js`：数据模型、IndexedDB 事务、页面交互。
- `build.py`：生成无外部依赖的完整 `index.html`。无需服务器或 npm 安装。

```sh
python3 build.py
```

正式页面直接运行，不再使用会禁止 IndexedDB 的不透明来源 sandbox iframe。多窗口修改在同一读写事务中读取最新存档，避免旧窗口恢复已删除记录。
